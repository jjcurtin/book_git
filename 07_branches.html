7  Branches

7.1 Why branch?

A branch is a parallel line of work inside one repository. It lets you try something without touching your main version.

Branches are useful when you want to:

  • Experiment with a risky change while keeping a working version safe
  • Draft a feature that isn’t ready for everyone yet
  • Keep main stable while work is in progress

You’ve been on a branch the whole time — the default one, called main. Now we’ll make a second.

7.2 Where you are now

List the branches in your repo:

git branch
* main

The * (shown in color) marks the branch you’re currently on. There’s only one so far, and git status reminds you of it too (On branch main).

7.3 Bucky wants to experiment

Bucky is tempted to add a vegetarian spread to the menu — but he doesn’t want to disturb the plan that already works.

Perfect job for a branch: he can draft the veggie options off to the side, decide if he likes them, and only then bring them into main.

7.4 Create and switch in one step

Make a new branch and move onto it:

git switch -c veggie-option
Switched to a new branch 'veggie-option'

The -c flag creates the branch and switches to it. It starts as an exact copy of main’s history.

Confirm where you are:

git branch
  main
* veggie-option

To create a branch without switching, use git branch <name>. In older Git, git checkout -b does what git switch -c does here.

7.5 Work on the branch

Draft the vegetarian items in a new file:

nano veggie.txt
Grilled veggie skewers
Portobello "brats" for the vegetarians

Save it to history as usual — this commit lands on veggie-option, not main:

git add veggie.txt
git commit -m "Draft vegetarian options"

7.6 main is untouched

Switch back and look:

git switch main
ls
brats.txt  cheese_curds.txt  desserts.txt

No veggie.txt here — it lives only on the branch. main is exactly as you left it. That isolation is the whole point of branching.

7.7 See the branches diverge

A decorated, graphed log shows how the branches relate:

git log --oneline --all --graph
* 7a1b2c3 (veggie-option) Draft vegetarian options
* 1d2e3f4 (HEAD -> main) Ignore scratch files and receipts
* c3d4e5f Add cheese curds and desserts

--all shows every branch and --graph draws the structure. Here veggie-option sits one commit ahead of main.

7.8 Keep it? Merge into main

Bucky likes the veggie options, so he brings them into main. First be on the branch you’re merging into, then merge:

git switch main
git merge veggie-option
Updating 1d2e3f4..7a1b2c3
Fast-forward
 veggie.txt | 2 ++
 1 file changed, 2 insertions(+)

main had no new commits of its own, so Git just fast-forwards it to catch up. veggie.txt is now part of main.

7.9 Clean up the branch

Once a branch is merged, delete it to keep things tidy:

git branch -d veggie-option
Deleted branch veggie-option (was 7a1b2c3).

If a branch is not fully merged, -d refuses and warns you — so you don’t lose work by accident. git branch -D (capital D) force-deletes when you really mean it.

7.10 When merges collide

Our merge was clean because main hadn’t changed. But if main and your branch both edited the same line, Git can’t fast-forward — the merge stops with a conflict.

You already know how to handle it: open the file, remove the <<<<<<<, =======, >>>>>>> markers, keep what you want, then git add and git commit. (See the Conflicts unit.)

7.11 Your turn

ImportantTry it

Branch, work, merge, clean up:

  1. From main, run git switch -c dessert-upgrade
  2. Add a line to desserts.txt, then git add and git commit
  3. git switch main and confirm the change isn’t there yet
  4. git merge dessert-upgrade, then git branch -d dessert-upgrade

7.12 Where we are

Branches let you work in parallel safely:

  • git branch lists branches; git switch -c <name> creates and moves onto one
  • Commits land on the current branch, leaving main safe
  • git merge <branch> brings the work together; git branch -d cleans up
ImportantKeep going

On GitHub, branches power pull requests — the standard way to propose and review changes with collaborators. That’s a great next thing to explore, with the cheatsheet at your side.
